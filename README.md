# Anthony Nash scientific portfolio

Public website: https://acnash.github.io/

This is a static, five-page GitHub Pages website. GitHub Pages publishes the committed HTML and assets from the root of `main`, without a server-side build.

Navigation: Home, Experience, Selected publications, Education, Research & projects.

Edit the content in `scripts/build_site.py` and the styling in `assets/site.css`, then run `python scripts/build_site.py`. Commit the generated HTML and sitemap together with the source changes. No third-party Python packages are required.

Preserve the Search Console verification tag and the existing manuscript URLs when editing.
